💰 Personal Expense Tracker

A modern and responsive Personal Expense Tracker built using HTML5, CSS3, JavaScript, and Bootstrap 5. This project helps users manage their daily expenses by recording transactions, tracking spending habits, and monitoring their financial activities through an intuitive and user-friendly interface.

Developed in Visual Studio Code, this project demonstrates front-end development skills, DOM manipulation, data management, and responsive web design principles.

✨ Features
Add and Manage Expenses
Track Income and Expenses
Real-Time Balance Calculation
Transaction History
Responsive User Interface
Interactive Dashboard
Form Validation
User-Friendly Navigation
Mobile-Friendly Design
Clean and Modern UI
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Bootstrap 5
Visual Studio Code
🎯 Project Objective

The objective of this project is to provide a simple and efficient way to track personal finances. It helps users monitor their spending, manage their budget, and gain better insights into their financial activities while showcasing practical front-end development skills.
